# ⚡ Kortex

> **Blazing fast AI-powered system hub & RAM optimizer for Windows, built with Rust & Tauri.**

Kortex — это быстрый системный хаб для Windows в стиле Raycast.

## 🚀 Возможности
* **RAM Freezer:** Очистка оперативной памяти и фоновых процессов по горячей клавише (`Alt + R`).
* **Raycast-UX:** Быстрый поиск по командам и навигация с клавиатуры.
* **Глобальный хоткей:** Вызов окна по нажатию `Alt + Space` из любой программы.
